# 空の制御（SkyTestScene）

変更・追加は Assets/Deverop/AT_Minakuchi 内。

## メインの設定

SkyTestSceneの「空の制御」を選ぶ。
- 「大気圏表示を有効にする」：ONで大気圏付近、OFFで通常の空。再生中の切り替えは「標準の切り替え時間（秒）」で補間する。
- 「雲の量」：0で雲なし、1で雲が多い状態。
- 「時刻」：昼夜・太陽・月・照明を制御。時刻はメインでの直接指定、またはTriggerの到達時刻指定で変更する。自動時間経過はない。
- 「テスト操作画面を表示」：大気圏チェックと雲量・時刻のスライダー。専用カメラは生成・移動・回転しない。

曇り・薄曇り・夜空のプリセットは削除。夜空は時刻によって表示する。

## Triggerでの設定

Prefab/SkyTransitionPoint.prefab を通過地点に置き、Box Colliderの範囲を調整する。

| 項目 | 動作 |
| --- | --- |
| 制御する空 | SkyEnvironment。省略時は有効な制御を検索 |
| 大気圏表示を有効にする | ONで大気圏へ、OFFで通常の空へ |
| 通過後の雲の量 | 0〜1。例えば0.1で少ない雲、0.8で多い雲 |
| 切り替え時間（秒） | 大気圏・雲量・指定した雲の高さの移行時間 |
| 到達時刻を指定 | ONの場合だけ指定時刻へ進める。OFFなら現在の時刻を維持 |
| このポイントで雲を上下させる | ONなら「移動先の雲の高さ」へ移動。OFFなら現在の高さを維持 |
| 通過対象オブジェクト | 指定対象と子Colliderのみ判定。タグより優先 |
| 対象タグ | 対象オブジェクト未指定時に判定。初期値Player、空欄で全対象 |
| 一度だけ発動 | OFFなら退出後の再通過で再発動 |

通過対象にColliderとRigidbody（Kinematic可）が必要。カメラ・プレイヤーの位置や速度、重力は変えない。
次のTriggerを途中で通過した場合、その瞬間の状態から新しい設定へ移行する。

## 雲の動き

- 元の5層の2Dノイズを土台にしたボリューム版を使用します。直前に試したランダム形状・シード・下面の追加照明は取り消しました。雲の模様、間隔、風、厚みはその前の状態です。
- 太陽方向の5点の密度を積算して光と影を付けます。上面だけ「上から見た雲の陰影」（初期値1）で影の範囲を誇張し、「上から見た雲の青み」（初期値0.65）で青みを重ねます。クリーム色の追加は削除しました。下面には上面用の誇張や色乗せを行いません。
- 「朝の影の濃さ」（初期値0.35）は朝〜10時の上面の陰影を弱める倍率です。10〜14時に通常の影へ滑らかに移行します。朝の黒つぶれを軽減し、午後の濃い影は維持します。
- 面の向きは、濃さを0〜1へ制限する前の連続したノイズ場から求めます。横筋対策として、浅い角度の視線はサンプル数を2倍にし、時間に依存しない空間的なずらしを使用します。散乱光と透過率を一度中間テクスチャへ描き、奥行きに沿う5×5フィルタで誤差を滑らかにしてから合成します。影と色の調整はフィルタとは独立しています。
- 中間テクスチャは縦横1/2サイズのRGBA16F。全画面の色をぼかす処理ではなく、雲の光と透過率だけを処理します。奥行きが異なる画素を除外し、建物などの輪郭へ背景の雲を広げないようにしています。細かい雲のディテールは少し柔らかくなります。対象機器での負荷計測は別途必要です。
- 「雲へ突入・離脱するときの演出」（初期値1、0で無効）は、雲の層の内部にいる間だけ近距離の白い雲を加える演出です。3Dノイズの濃淡が実際のカメラ移動や風、Triggerの雲の上下移動で流れ、入口・出口で滑らかに消えます。雲量が少ない場面でも突入感を出すため、遠景の雲模様とは独立した補助演出です。物体までの奥行きを尊重し、雲の層の外側では完全に無効になります。
- 描画品質は初期値40（16〜64）。「雲の影の強さ」は初期値1.3。64³の3Dテクスチャ（RGBA8、1MiB）のGチャンネルを奥行き方向の揺らぎと通過中の濃淡に使用します。Editor/GenerateCloudNoise.pyで再生成できます。
- PC_RendererとMobile_RendererにCloudVolumeFeatureを登録済み。雲が有効なときだけ、不透明物体と空の描画後・半透明物体の描画前に合成します。奥行きテクスチャで物体までの距離を取得し、雲の内部では遠い物体ほど霞みます。半透明の物体やパーティクルにはこの霞は適用されません。新しいRendererを使う場合は同じFeatureとシェーダー・ノイズ参照を追加してください。URP RenderGraphを使用します。
- 「立体メッシュの雲を使う（開始時）」をONにして再生し直すと、前の試作メッシュ版に切り替わります。元の5層の2Dノイズで上面・下面を膨らませ、外周を側面で閉じたメッシュです。コライダーはありません。雲の方式は同時に描きません。
- メッシュ範囲はカメラ周囲18,000、6,000〜8,500の距離で輪郭をディザ透過します。外向きの面のみ描画し、上面から下面の裏側が透けて二層に見えることを防ぎます。雲の内部の散乱は再現しないため、内部では面が消える試作です。実機の見た目・負荷の検証が必要です。

- ボリューム版は近距離に多くサンプルを配分し、雲の内部を横に見たときも近くの密度を拾います。十分に不透明になったところで計算を打ち切ります。最大描画距離24,000、16,000以遠で徐々に薄くなります。
- 雲海向け初期値は、雲の中心の高さ−400、厚み400、濃さ2、雲量1、模様の大きさ1200。雲の上端はY=−200で、Y=0付近のカメラから約200下に雲海が見える設定です。別の高度のコースでは「雲の高さ＝カメラのY座標−400」を目安に調整してください。
- 「雲の厚み」は雲の高さを中心とする上下の幅、「雲の濃さ」は光の通りにくさです。Triggerで雲量を小さくすると雲海に隙間が増えます。
- 従来の平面描画よりGPU負荷が増えます。対象機器でフレーム時間を確認してください。SkyAssetVersionの背景画像版には適用していません。

- 「雲を流す」：横方向の流れをON／OFF。「雲の流れる方向と速さ」「雲の流れる速さの倍率」で調整。停止と再開で位置は飛ばない。
- 雲の高さは雲の中心のワールド座標Y。大きいほど上、小さいほど下。マイナス値も指定できる。カメラ位置から描画するため、上昇して雲の上端を超えると、見下ろした方向に雲の上面が見える。横移動でも雲との位置関係が変わる。
- メインでは「開始時の雲の高さ」を指定し、再生中の上下移動はTriggerだけで行う。大気圏ON／OFFは雲の高さを変えない。
- 通過演出は層の内部にいる度合いと視線上の近距離ノイズで調整します。一定の白を画面全体へ貼る処理ではなく、物体との距離にも応じて霞みます。
- カメラ位置はシェーダーで描画中のカメラから取得する。Controllerへのカメラ指定は不要。「大気圏表示時の見た目の高度」は使用しない。

## 夕焼けと夜

夕焼けの色・強さ・広がりはメインの設定を使用。18時以降に地平線へ縮み、初期設定では19.25時に消える。
夜色は17時から上空より下り、21.5時に地平線まで届く。各開始・終了時刻を調整可能。星は夜色になった場所から表示。
色の設定値は自動で上書きしない。

## 検証

2026年10月27日のボリューム版は、Unity 6000.3.23f1・URP 17.3.0の専用検証プロジェクトでコンパイルと描画を確認。雲の上・中・下、10時と16時の陰影、雲の中の近距離／遠距離の不透明物体の霞をプレビューしています。元のノイズへの変更後は、前進・上昇して層を抜ける12枚の連続プレビューも確認し、雲の内部より上空で青空の見える範囲が増えることを検証しています。復元後は上面・下面が直前のランダム形状変更前と画素単位で一致すること、上昇・下降、固定カメラに対して雲の高さを動かすTrigger相当の通過、雲量0.34での突入演出を確認。元のゲームシーン全体での動作・フレーム時間は未計測です。
「水口 > 空 > 立体雲の光と影をプレビュー」で同じ確認ができます。出力先はTemp/CloudPreviews（環境変数CODEX_CLOUD_PREVIEW_DIRで変更可能）です。

2026年10月22日に試した更新省略・描画分岐の最適化は、雲の見え方が変わったとの報告を受けて取り消した。
数値比較だけでは画面の同一性を保証できないため、最適化前の更新・描画処理へ戻している。雲量や色の設定値は変更していない。

「水口 > 空 > 導入済みアセットを検証」でPrefabとシェーダーの参照を確認。
「水口 > 空 > 夕暮れの段階をプレビュー」は編集モード専用の手動検証。自動実行はしない。
「水口 > 空 > テストシーンを作成・更新」はPrefabとテスト用Triggerを初期設定で再生成するため、調整済みの場合は注意。
