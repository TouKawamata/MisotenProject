# アセット版の空・実験用コピー

`Scene/SkyAssetTestScene.unity` は、ディスクに保存されている `SkyTestScene.unity` のコピーです。Unity内の未保存変更は含まれません。

- 空のプレハブ：`Prefab/AssetSkyEnvironment.prefab`
- 通過ポイント：`Prefab/AssetSkyTransitionPoint.prefab`
- 専用のスクリプト・マテリアル・シェーダー：このフォルダー内

空関連の参照は全て複製先へ差し替えています。元の空システムとは別々に編集できます。コース・プレイヤー等の既存ゲームアセットは元の参照を維持しています。

Skybox Series Freeの画像を組み込み済みです。曇りはSunlessCirruscover、薄曇りはSkyhighFluffycloudField、夜空はCoriolisNight4k、大気圏付近はPlanetaryEarthを使用します。
専用プレハブの「アセットの背景画像」で4種の画像・明るさ・向きを変更できます。
曇り／薄曇りは雲の量、夜空は時刻、大気圏付近は移行度に応じて滑らかにブレンドします。ポイントごとの秒数・到達時刻・雲の高さ設定も引き継いでいます。

画像に描かれた雲や太陽・月は画像の一部なので個別には動きません。動かせる雲は別に重ねています。「動く雲の重ね具合」で濃さを変えられ、0なら背景画像だけになります。
「動く太陽と月を重ねる」は画像内の天体との二重表示を避けるため初期値OFFです。ONにすれば時刻で動く天体を追加できます。ライトによる時刻の連動は常に維持します。
大気圏付近では頭上の追加雲を薄くし、宇宙の背景を見せます。下側の追加雲は各ポイントの高さ指定に応じて表示します。
テストカメラ制御は初期値OFF。雲の霞・雲の流れ・雲の上下指定はメイン版と同様に調整できます。

「水口 > アセット版の空 > 検証とプレビュー作成」で背景参照・シェーダーを検証し、Previewsへ曇り・夜空・大気圏の画像を出力します。

元の「水口 > 空 > テストシーンを作成・更新」は元のシーン用です。このコピーを再生成する操作ではありません。

## 夕焼け

メインのInspectorの「夕焼けの色づけを有効にする」「夕焼けの色」「夕焼けの強さ」「夕焼けの広がり」で調整できます。16〜20時に出現し、18時付近で最も強くなります。
初期値では強さ・広がりを0.85にして、地平線から上空へ広くオレンジ色を重ねています。背景画像と追加の雲の両方が色づき、大気圏付近へ移ると夕焼けは消えます。
